# Website Portofolio — Siti Fadiyah Maulida

Website portofolio statis, responsif, dan dapat dipublikasikan melalui GitHub Pages. Dibuat dengan HTML, CSS, dan JavaScript tanpa framework atau proses build.

## Isi folder
- `index.html` — struktur dan konten website.
- `style.css` — desain responsif dan gaya visual.
- `script.js` — navigasi mobile, animasi saat scroll, serta galeri foto.
- `assets/` — foto, dokumentasi, PDF portofolio, dan CV PDF.

## Menjalankan di komputer
1. Ekstrak folder ZIP.
2. Buka folder `fadiyah-portfolio` di Visual Studio Code.
3. Klik kanan `index.html` lalu pilih **Open with Live Server** jika ekstensi Live Server sudah terpasang, atau buka `index.html` langsung melalui browser.
4. Untuk memperbarui konten, edit `index.html`; untuk warna dan ukuran, edit `style.css`.

## Publikasi ke GitHub Pages
1. Login ke GitHub dan buat repository baru, misalnya `fadiyah-portfolio`.
2. Unggah semua file dan folder di dalam folder proyek ke repository (pastikan `index.html` ada di root repository).
3. Buka **Settings → Pages**.
4. Pada bagian **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, lalu tekan **Save**.
6. Tunggu proses publikasi selesai; GitHub akan menampilkan alamat website di halaman Pages.

## Catatan konten
- IPK yang digunakan: **3,80**, sesuai konfirmasi pemilik portofolio.
- Tombol **Download CV** mengarah ke `assets/cv-siti-fadiyah.pdf`.
- Sertifikat Zahir Accounting disebutkan di portofolio; file sertifikat terpisah belum disertakan.
- Foto sampul menggunakan PNG transparan yang sudah tersedia di aset.
- Beberapa foto dokumentasi diambil dari file portofolio yang diberikan.

## Catatan teknis
Google Fonts digunakan untuk tipografi dan memerlukan koneksi internet. Website lainnya adalah file statis dan tidak memerlukan database atau login.


## Pembaruan aset
Website menggunakan foto profil transparan pada bagian Tentang Saya, logo asli Universitas Pelita Bangsa, HIMA Eksyar, Chiclin, DYORA, dan Zahir Accounting, serta CV PDF terbaru yang dikirimkan.
